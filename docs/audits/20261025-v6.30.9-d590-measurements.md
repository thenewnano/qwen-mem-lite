## 做法（附录 A `measure.mjs`）

每个样本：私有副本，子进程里 `CLAUDE_MEM_DIR` 指向它，HOME、TMPDIR、CLAUDE_PROJECT_DIR 都在私有目录下。

1. 产品的打开流程（`ensureDbWithWalRecovery`）一次，就像 doctor 之前任何一个钩子做的；打不开的 14 个不在这个人群里（那是 doctor 的
   "库不能用"那条路）。
2. doctor 的数据库步骤，在一个读写句柄上：`checkFTSIntegrity`，不通过就 `rebuildFTS`（6.30.8 的 doctor 到此为止），
   然后 `checkStoreIntegrity`（新步骤）。
3. 第 2 步前、FTS 那步后、新步骤后各数一次 observations：`NOT INDEXED`（表本身）和 `count(*)`（DB stats 打印的那个数）。

"旧判定"= 只看 FTS 那步：`green`（FTS 检查通过）、`fts-rebuilt`（重建后没有报错）、`fts-fail`（重建报错，6.30.8 的 doctor 打 ✗）。

| | 个数 |

| 样本 / 能打开 | 2,769 / 2,755 |

旧判定 → 新判定：green → ok 782、green → rebuilt 143、green → damaged 365；fts-rebuilt → ok 548、→ rebuilt 19、→ damaged 243；
fts-fail → damaged 653、→ ok 1、→ unchecked 1。

- 6.30.8 的 doctor 在 1,290 个样本上 FTS 检查通过（数据库部分全绿）：新步骤在其中 143 个上重建后通过，365 个报 ✗。
- `count(*)` 在重建后下降：120 个（rebuilt 1，damaged 119），例如 main21-46 1,195 → 15（表里 15）、main21-76 的
  observation_files 600 → 445。doctor 把它们列成 "N before, M after"。
- observations 的 `NOT INDEXED` 计数在新步骤前后：2,570 个能数的，没有一个变化；185 个前后都抛 SQLITE_CORRUPT（表页坏了）。
- 新步骤结束后句柄上留着事务的：0。

## 设计上被这次测量推翻的两处（第一次跑，`28f57552` 的初版）

- 初版把 integrity_check 抛出的错误一律算"没查"：721 个样本抛的是 SQLITE_CORRUPT（"database disk image is malformed"），
  那是查到了损坏。现在 SQLITE_CORRUPT / SQLITE_NOTADB 的抛出算一行失败结果，照样重建、再查。
- 初版不报计数：第一次跑有 79 个样本 `count(*)` 在重建后下降（另有 4 个上升），全在 damaged 里，例如 main21-46 从 1,195
  降到 15，doctor 只打 ✗ 和 SQLite 的原话，DB stats 那一行从 1,195 变成 15 没有说明；fixture `lost-rows`（表 3 行、
  索引列 12 行）落在 rebuilt 里，打的是 ✓。现在重建放进一个 `BEGIN IMMEDIATE` 事务，前后数每张有索引的表，下降的
  在 ✓ 的位置改打 ⚠ 列出来，✗ 下面也列。

## 附录 A：measure.mjs

```js
// node measure.mjs <population> <out.jsonl>: D#590(a). For each plant of the D#546 regression set
// (tasks/d546/ruler/plants.mjs), on a private copy, in a child process with CLAUDE_MEM_DIR on it:
//   1. the product opener (ensureDbWithWalRecovery) once, as any hook does before doctor runs; a store
//      that does not open is out of this population (doctor's unusable-store path);
//   2. doctor's database steps on a read-write handle: checkFTSIntegrity, rebuildFTS when it fails
//      (the old doctor ends here), then checkStoreIntegrity (the new step);
//   3. observations counted NOT INDEXED (the table) and by the planner (what DB stats prints) before
//      step 2, after the FTS step and after the new step.
import { spawnSync } from 'node:child_process';
import { appendFileSync, mkdirSync, rmSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { WORK, build869, copyPair, plant869, plants869, richPlants } from '../d546/ruler/plants.mjs';
const TREE = new URL('../../', import.meta.url).pathname;
const [pop, out] = process.argv.slice(2);
const slot = `d590a-${pop.replace(/:/g, '_')}`;
let plants;
if (pop === '869') {
  build869();
  plants = plants869().map((x) => ({ id: x.id, make: (d) => plant869(d, x) }));
} else {
  const [v, s, c] = pop.split(':');
  plants = richPlants(v, Number(c), Number(s), slot).plants;
}
const home = join(WORK, slot, 'home');
mkdirSync(join(home, 'tmp'), { recursive: true });
mkdirSync(join(home, 'proj'), { recursive: true });
const env = { HOME: home, TMPDIR: join(home, 'tmp'), CLAUDE_PROJECT_DIR: join(home, 'proj'), PATH: process.env.PATH, MEM_NO_AUTO_ADOPT: '1', CLAUDE_MEM_SKIP_UPDATE: '1', CLAUDE_MEM_SKIP_MAINTAIN: '1', CLAUDE_MEM_SKIP_SAVE_ENRICH: '1', MEM_QUIET_HOOKS: '1' };
const child = `
const s = await import(${JSON.stringify(join(TREE, 'schema.mjs'))});
const Database = (await import(${JSON.stringify(join(TREE, 'node_modules/better-sqlite3/lib/index.js'))})).default;
const o = {};
try { const db = s.ensureDbWithWalRecovery(); db.close(); o.opens = true; } catch (e) { o.opens = false; o.openErr = e.code || e.message; }
if (o.opens) {
  const rw = new Database(s.DB_PATH); rw.pragma('busy_timeout = 3000');
  const t = () => { try { return rw.prepare('SELECT count(*) FROM observations NOT INDEXED').pluck().get(); } catch (e) { return 'ERR ' + e.code; } };
  const c = () => { try { return rw.prepare('SELECT count(*) FROM observations').pluck().get(); } catch (e) { return 'ERR ' + e.code; } };
  o.t0 = t(); o.c0 = c();
  const f = s.checkFTSIntegrity(rw); o.ftsHealthy = f.healthy; o.ftsBusy = f.busy;
  if (!f.healthy && !f.busy) { const rb = s.rebuildFTS(rw); o.ftsErrors = rb.errors.length; }
  o.t1 = t(); o.c1 = c();
  const r = s.checkStoreIntegrity(rw); o.state = r.state; o.row0 = r.rows[0]; o.after0 = r.after?.[0]; o.error = r.error; o.rebuildErrors = r.rebuildErrors?.length; o.fell = r.fell?.map((x) => x.table + ':' + x.before + '->' + x.after); o.busy = r.busy; o.inTx = rw.inTransaction;
  o.t2 = t(); o.c2 = c();
  try { o.icFinal = rw.prepare('PRAGMA integrity_check(1)').pluck().get(); } catch (e) { o.icFinal = 'ERR ' + e.code; }
  rw.close();
}
process.stdout.write(JSON.stringify(o));
`;
writeFileSync(out, '');
const dir = join(WORK, slot, 'run');
for (const pl of plants.slice(0, Number(process.env.LIMIT || Infinity))) {
  const made = pl.make(join(WORK, slot, 'cur'));
  const p = typeof made === 'string' ? made : made.p;
  copyPair(p, dir);
  const r = spawnSync(process.execPath, ['--input-type=module', '-e', child], { env: { ...env, CLAUDE_MEM_DIR: dir }, cwd: join(home, 'proj'), encoding: 'utf8', timeout: 120000 });
  let o;
  try { o = JSON.parse(r.stdout); } catch { o = { childFailed: true, status: r.status, err: (r.stderr || '').slice(-300) }; }
  appendFileSync(out, JSON.stringify({ id: pl.id, ...o }) + '\n');
}
rmSync(join(WORK, slot), { recursive: true, force: true });
```

## 附录 B：sum3.mjs

```js
// node sum3.mjs out3/*.jsonl: the numbers the CHANGELOG and the measurement note quote.
import { readFileSync } from 'node:fs';
const rows = process.argv.slice(2).flatMap((f) => readFileSync(f, 'utf8').trim().split('\n').map((l) => JSON.parse(l)));
const tally = (m, k) => m.set(k, (m.get(k) || 0) + 1);
const pop = (id) => (id.startsWith('main') ? 'main' : id.startsWith('two') ? 'two' : id.startsWith('log') ? 'log' : '869');
const old = (r) => (r.ftsBusy ? 'busy' : r.ftsHealthy ? 'green' : r.ftsErrors ? 'fts-fail' : 'fts-rebuilt');
const opens = rows.filter((r) => r.opens);
const out = {
  plants: rows.length,
  childFailed: rows.filter((r) => r.childFailed).length,
  opens: opens.length,
  notOpen: rows.filter((r) => r.opens === false).length,
  state: Object.fromEntries([...opens.reduce((m, r) => (tally(m, r.state), m), new Map())]),
  byPopulation: Object.fromEntries([...new Set(opens.map((r) => pop(r.id)))].map((p) => [p, Object.fromEntries([...opens.filter((r) => pop(r.id) === p).reduce((m, r) => (tally(m, r.state), m), new Map())])])),
  oldVsNew: Object.fromEntries([...opens.reduce((m, r) => (tally(m, `${old(r)} -> ${r.state}`), m), new Map())].sort((a, b) => b[1] - a[1])),
  tableRowsChanged: opens.filter((r) => r.t1 !== r.t2).length,
  tableCountErr: opens.filter((r) => typeof r.t1 !== 'number').length,
  transactionLeftOpen: opens.filter((r) => r.inTx).length,
  rebuiltPassAfter: opens.filter((r) => r.state === 'rebuilt' && r.icFinal === 'ok').length,
  fellRebuilt: opens.filter((r) => r.state === 'rebuilt' && r.fell?.length).length,
  fellDamaged: opens.filter((r) => r.state === 'damaged' && r.fell?.length).length,
  fellExamples: opens.filter((r) => r.fell?.length).slice(0, 4).map((r) => `${r.id} ${r.state} ${r.fell.join(',')}`),
  unchecked: opens.filter((r) => r.state === 'unchecked').map((r) => `${r.id}: ${r.error}`),
  unrebuilt: opens.filter((r) => r.state === 'unrebuilt').length,
};
console.log(JSON.stringify(out, null, 1));
```
