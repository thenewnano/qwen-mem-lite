# v6.30.5 measurements: the restore command's snapshot check (D#553)

Withdrawn: the round-2 delta review of 0904e37c ([r2-delta](20261023-v6.30.5-r2-delta.md)) found
a P1 in the check measured here: a snapshot whose only damage is its FTS5 index is rejected, though
doctor rebuilds such an index without loss. 8924b6a5 reverts the check (7b0adf11, 73a01e99); 6.30.5
ships the restore command as in 6.30.4. The numbers below describe the withdrawn tree.

Taken 2026-10-23 on `main` at 73a01e99 (the pre-tag review repairs on top of 7b0adf11) (`lib/db-unusable.mjs`
`checkSnapshot` and `dbUnusableRemedy`), Linux, Node 26.8.1, better-sqlite3 13.0.3
(SQLite 3.53.4), system sqlite3 3.46.1. Populations: the four of the v6.31.0 round-2 measurements
([20261022-v6.31.0-d550-r2-measurements.md](20261022-v6.31.0-d550-r2-measurements.md)): `869`,
`main:21:800`, `two:22:300`, `log:23:800`, 2,769 plants generated by `tasks/d546/ruler/plants.mjs`
(archived in [20261022-v6.31.0-d546-ruler.md](20261022-v6.31.0-d546-ruler.md)). Every child ran with
HOME, TMPDIR and CLAUDE_PROJECT_DIR inside `~/.cache/tmp/d553`, MEM_NO_AUTO_ADOPT=1,
CLAUDE_MEM_SKIP_UPDATE=1, CLAUDE_MEM_SKIP_MAINTAIN=1, CLAUDE_MEM_SKIP_SAVE_ENRICH=1,
MEM_QUIET_HOOKS=1, and a PATH of a directory holding node alone, then /usr/bin:/bin.

Population: the plants that fail the round-2 ruler, `checkIntegrity` of 602b480e
(`lib/db-integrity.mjs`, `PRAGMA integrity_check` on a read-only handle), on the store as found. For
each: one `cli.mjs delete 5 --confirm` of this tree on a copy, then on the snapshot it left:

- `old`: the 602b480e read-only check;
- `neu` / `verdict`: this tree's `checkSnapshot` (whole file in memory, `PRAGMA integrity_check(1)`,
  then an `observations` table): `ok`, `bad`, or `unchecked` with a `reason`;
- `cli`: the system sqlite3, `PRAGMA integrity_check(1);` on a private copy (read-write);
- `wrote`: whether the directory listing beside the snapshot changed across the `neu` check;
- `kind` / `names`: `dbUnusableRemedy(<db>, 'file is not a database', { Database })` on that directory,
  that is, the remedy doctor would print had the store then stopped opening, and whether its command
  names this snapshot;
- `storeObs` / `templateObs` / `snapObs`: `SELECT count(*) FROM observations` on a read-only copy of the
  store as found, of the population's unplanted template (its store before any damage), and of a
  passing snapshot.

- The old read-only check, `checkSnapshot`'s `ok` and the system sqlite3 agree on all 661 snapshots:
  200 pass. The same 1,641 / 661 / 200 split as the round-2 claims review measured with 6.31.0's tree
  (r2-claims 2.20), and as this measurement's first run on 7b0adf11 (2026-10-22).
- `checkSnapshot` calls 456 of the other 461 `bad` and 5 `unchecked`; all 5 fail the other two checks
  too. On 4 (869 set, p74/p76, variants 4 and 5) integrity_check stops with `SQLITE_NOMEM`, on 1
  (`main21-112`) with `SQLITE_ERROR` (`invalid fts5 file format`). For those doctor prints the
  snapshot's path and reason and no command.
- `wrote` is false on all 661.
- doctor restores on the 200 and sets the file aside on 456; it never restores a snapshot that is not
  `ok` (`restoreWhenFails` 0).

## A passing snapshot is not a copy of every row the store held

55 of the 200 passing snapshots hold fewer observations than their population's store held before
the damage (`passBelowTemplate`): 52 in the 869 set hold 200 of 241, 3 in the log set 1,195 of 1,495.
Compared with the store as found instead, 6 differ (`passObsDiffer`, 241 → 200) and 49 cannot be
compared, because the read-only count of the damaged store errors (`passObsStoreErr`); a first
version of this section reported only the 6 (claims review of be5c42b9, finding 2).

Not the snapshot, on the 869 plants probed: the product's open (`schema.mjs`
`ensureDbWithWalRecovery`) retries a corruption error with the log kept, then deletes `-wal` and
`-shm` and opens again, so the 41 rows committed only in the damaged log are gone before `delete`
takes its snapshot. The 3 log-set snapshots were not probed. `why241.mjs` shows it with one
`cli.mjs recent 300` on three 869 plants (`obsBefore` / `obsAfter`: a read-only copy of the store before and after the call):

### snapcheck3.mjs

```javascript
// node snapcheck3.mjs <population> <k> <K> <out>: D#553. For each plant failing the read-only check of
// 602b480e (lib/db-integrity.mjs checkIntegrity, the round-2 ruler): this tree's `cli.mjs delete 5 --confirm`
// on a copy; for the snapshot it leaves: the 602b480e read-only check, this tree's checkSnapshot (in
// memory: ok / bad / unchecked), the system sqlite3's `PRAGMA integrity_check(1)` on a private copy
// (read-write), files written beside the snapshot by the new check, the remedy doctor would print if the
// store then stopped opening, and observation counts: the damaged store as found, the unplanted template
// of the population (its store before any damage), and the snapshot.
import { spawnSync } from 'node:child_process';
import { appendFileSync, copyFileSync, mkdirSync, readdirSync, readFileSync, statSync } from 'node:fs';
import { join } from 'node:path';
import Database from 'better-sqlite3';
import { DB, WORK, build869, copyPair, plant869, plants869, richPlants, richTemplate } from '../d546/ruler/plants.mjs';
import { checkIntegrity } from './db-integrity-602b480e.mjs';
const TREE = new URL('../../', import.meta.url).pathname;
const { checkSnapshot, dbUnusableRemedy } = await import(`${TREE}/lib/db-unusable.mjs`);
const [pop, kS, KS, out] = process.argv.slice(2);
const k = Number(kS), K = Number(KS), slot = `s3-${pop.replace(/:/g, '_')}-${k}`;
let plants;
if (pop === '869') { build869(); plants = plants869().map((x) => ({ id: x.id, make: (d) => plant869(d, x) })); }
else { const [v, s, c] = pop.split(':'); plants = richPlants(v, Number(c), Number(s), slot).plants; }
const count0 = (p) => { const d = new Database(copyPair(p, join(WORK, 'sc3', slot, 'tpl')), { readonly: true }); try { return d.prepare('SELECT count(*) FROM observations').pluck().get(); } finally { d.close(); } };
const templateObs = pop === '869' ? count0(join(build869(), 'unplanted', DB)) : count0(richTemplate(pop.split(':')[0]));
const home = join(WORK, 'sc3', slot, 'home');
mkdirSync(join(home, 'tmp'), { recursive: true }); mkdirSync(join(home, 'proj'), { recursive: true });
const env = { HOME: home, TMPDIR: join(home, 'tmp'), CLAUDE_PROJECT_DIR: join(home, 'proj'), PATH: process.env.PATH, MEM_NO_AUTO_ADOPT: '1', CLAUDE_MEM_SKIP_UPDATE: '1', CLAUDE_MEM_SKIP_MAINTAIN: '1', CLAUDE_MEM_SKIP_SAVE_ENRICH: '1', MEM_QUIET_HOOKS: '1' };
const count = (p, ro) => { let db; try { db = new Database(p, { readonly: ro, fileMustExist: true }); return db.prepare('SELECT count(*) FROM observations').pluck().get(); } catch (e) { return `ERR ${e.code}`; } finally { try { db?.close(); } catch {} } };
for (let i = 0; i < plants.length; i++) {
  if (i % K !== k) continue;
  const pl = plants[i];
  const p = pl.make(join(WORK, 'sc3', slot, 'cur'));
  const icp = copyPair(p, join(WORK, 'sc3', slot, 'ic'));
  const ic = checkIntegrity(icp);
  if (ic.ok || ic.notChecked) continue;
  const storeObs = count(copyPair(p, join(WORK, 'sc3', slot, 'cnt')), true);
  const dir = join(WORK, 'sc3', slot, 'run');
  copyPair(p, dir);
  const del = spawnSync(process.execPath, [join(TREE, 'cli.mjs'), 'delete', '5', '--confirm'], { env: { ...env, CLAUDE_MEM_DIR: dir }, cwd: join(home, 'proj'), encoding: 'utf8', timeout: 60000 });
  const bak = readdirSync(dir).find((n) => n.endsWith('.bak'));
  if (!bak) { appendFileSync(out, JSON.stringify({ id: pl.id, delRc: del.status, bak: null }) + '\n'); continue; }
  const sp = join(dir, bak);
  const old = checkIntegrity(sp);
  const before = readdirSync(dir).sort().join(',');
  const neuCheck = checkSnapshot(sp, Database);
  const neu = neuCheck.verdict === 'ok';
  const wrote = readdirSync(dir).sort().join(',') !== before;
  const cp = join(WORK, 'sc3', slot, 'cli.bak'); copyFileSync(sp, cp);
  const cli = spawnSync('sqlite3', [cp, 'PRAGMA integrity_check(1);'], { encoding: 'utf8', timeout: 60000 });
  const cliOk = cli.status === 0 && cli.stdout.trim() === 'ok';
  const remedy = dbUnusableRemedy(join(dir, DB), new Error('file is not a database'), { Database });
  const snapObs = neu ? count(sp, true) : null;
  appendFileSync(out, JSON.stringify({ id: pl.id, delRc: del.status, bak: statSync(sp).size, old: old.ok ? 'ok' : old.notChecked ? 'notChecked' : 'fail', neu, verdict: neuCheck.verdict, reason: neuCheck.reason, templateObs, cli: cliOk ? 'ok' : `fail ${(cli.stdout + cli.stderr).trim().slice(0, 80)}`, wrote, kind: remedy.kind, names: remedy.command.includes(sp), storeObs, snapObs }) + '\n');
}
```

### sum3.mjs

```javascript
// node sum3.mjs <outDir>: summary of snapcheck3.mjs's rows, per population and in total.
import { readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
const dir = process.argv[2];
const rows = readdirSync(dir).filter((f) => f.endsWith('.jsonl')).flatMap((f) =>
  readFileSync(join(dir, f), 'utf8').split('\n').filter(Boolean).map((l) => ({ pop: f.replace(/-\d+\.jsonl$/, ''), ...JSON.parse(l) })));
const sum = (rs) => {
  const s = rs.filter((r) => r.bak !== null);
  const c = (f) => s.filter(f).length;
  return {
    failingPlants: rs.length, snapshots: s.length, emptySnapshots: c((r) => r.bak === 0),
    oldOk: c((r) => r.old === 'ok'), oldNotChecked: c((r) => r.old === 'notChecked'), newPass: c((r) => r.neu), cliOk: c((r) => r.cli === 'ok'),
    newVsOldDisagree: c((r) => r.neu !== (r.old === 'ok')), newVsCliDisagree: c((r) => r.neu !== (r.cli === 'ok')),
    wroteBeside: c((r) => r.wrote), kindRestore: c((r) => r.kind === 'restore'), kindSetAside: c((r) => r.kind === 'set-aside'),
    restoreNamesIt: c((r) => r.kind === 'restore' && r.names), restoreWhenFails: c((r) => r.kind === 'restore' && !r.neu),
    verdictOk: c((r) => r.verdict === 'ok'), verdictBad: c((r) => r.verdict === 'bad'), verdictUnchecked: c((r) => r.verdict === 'unchecked'),
    kindUnknown: c((r) => r.kind === 'unknown'),
    passObsEqualsStore: c((r) => r.neu && r.snapObs === r.storeObs), passObsStoreErr: c((r) => r.neu && typeof r.storeObs === 'string'),
    passObsDiffer: s.filter((r) => r.neu && typeof r.storeObs === 'number' && r.snapObs !== r.storeObs).map((r) => `${r.id}:${r.storeObs}->${r.snapObs}`),
    templateObs: [...new Set(s.map((r) => r.templateObs))],
    passBelowTemplate: c((r) => r.neu && r.snapObs < r.templateObs),
    passBelowTemplateBy: [...new Set(s.filter((r) => r.neu && r.snapObs < r.templateObs).map((r) => `${r.templateObs}->${r.snapObs}`))],
  };
};
const pops = [...new Set(rows.map((r) => r.pop))];
for (const p of pops) console.log(p, JSON.stringify(sum(rows.filter((r) => r.pop === p))));
console.log('TOTAL', JSON.stringify(sum(rows), null, 1));
```
