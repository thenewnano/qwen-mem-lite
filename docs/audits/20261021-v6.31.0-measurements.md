## D#522: the user-prompt scrub at the 256 KiB cap

The D#511 closure (v6.30.2) rested on a rule written before measuring: the worst known shape
takes at most 1.25 s at the hook's input cap. The defects review of v6.30.2 (F6) listed shapes
12-21% slower than v6.30.1 without testing them at the cap. Here they are rebuilt from its table
and appended to the archived `shapes.mjs`
(docs/audits/20261021-v6.30.2-pretag-measurements.md), and `e2e2.mjs` from that file is run
unchanged, 5 trials per shape with the two trees alternating.

**Run 1, 2026-10-21 06:53Z** (load 0.6 → 5.3). Arms: v6.30.1 (5443e879) and v6.30.2 (20d94507).

The twelve-escape-depth family over a `\x` tail is above 1.25 s on both releases. The hook

first 14096 characters took 67.8 ms. Every shape rebuilt to fill 14096 characters took at most
89.5 ms (`win.mjs`, `win2.mjs`).

**Run 2, 07:08Z** (load 7-12). Arms: v6.30.2 and the scrub window (c5e4654a: `scrubHead`, a
window 4096 characters past the 10000 kept, with the token cut by its edge dropped). The slowest
of the 20 shapes, wall:
- v6.30.2: 2334 ms (f6EscAbCx);
- the window: 304 ms (f6EscAbCx).

Every shape on the window was at most 304 ms wall and 274 ms CPU.

**Leak and equality** (`headfuzz.mjs`, seeds 1-6, 300 + 5 x 1000 prompts longer than the
window). Each prompt is random prose with planted secrets:
- `ghp_`, `sk-ant-`, `AKIA`, `password=` and Bearer tokens;
- RSA keys with and without END;
- JSON-escaped keys.

The oracle: no 12-character fragment of a planted value appears in `scrubHead`'s output unless
the whole-prompt scrub also keeps it. Results:
- `scrubHead`: 0 fragments stored, 0 pre-existing.
- The output differed from `scrubSecrets(p).slice(0, 10000)` only when the window's own
  replacements shrank it by 3896+ characters, which puts its edge inside the kept text
  (3736 such inputs).
- A variant that stores `p.slice(0, 10000)` unscrubbed: the same oracle found 19679 fragments.

## D#524: can a damaged WAL frame reach the FTS-rebuild arm? (closed, no change)

Question: `ensureDbWithWalRecovery`'s FTS arm (entered when the first `ensureDb()` throws an error
`isFtsCorruptionError` accepts) closes its raw read-write handle with a plain `raw.close()`. Could
that close checkpoint a damaged WAL frame into the main file, the way failed opens did before
bcbe1f51? Pre-registered rule (local spec): reproduce with a real damaged frame. If arm A (as
shipped) ends worse than arm B (`closeWithoutCheckpoint(raw)`), fix. If it cannot be reproduced,
record what was ruled out and close.

Run 2026-10-21 by a subagent on `git archive 20d94507`, with better-sqlite3 13.0.3, SQLite 3.53.4
and Node v26.8.1. Fixtures were on ext4 under `~/.cache/tmp`, children with `HOME`/`TMPDIR` in the
work dir, `MEM_NO_AUTO_ADOPT=1` and the LLM keys removed. Load average was up to 31.8 (another
session's suite), and no timings were taken.

### Fixture
- Pristine main: `ensureDb()` on an empty dir, seeded with 3 sessions, 300 observations,
  200 events (search_terms filled), 20 summaries and 50 prompts, then `wal_checkpoint(TRUNCATE)`.
  536,576 B. A plain re-open leaves it unchanged.
- Clean WAL: 4 transactions on a raw connection with the FTS triggers firing, adding 40
  observations, 40 events and 12 prompts. 153 frames, 630,392 B, 50 distinct pages.
- Damage: the newest frame of one page is damaged, then the whole checksum chain is re-signed
  (the `plantCorruptWal` arithmetic), with a pristine main and a 32 KB zero `-shm`.
  `validFrames` 153/153 in every trial.
- Pages: identified with `dbstat` on the checkpointed reference, `sqlite_master.rootpage` and a
  leaf-cell parse for rowid 10. The structure records are at `events_fts_data` p107,
  `observations_fts_data` p65 and `user_prompts_fts_data` p40.
- Variants:
  - `vac`: a VACUUM in the WAL, so every page (136) has a frame.
  - `behind`: version row 48, forcing the migration pass.
  - `nullterms`: WAL events with NULL `search_terms`, so the backfill runs.

### Q1: does a real damaged frame route to the FTS arm? No, in 0 of 31,353 trials
Damage per page:
- a 64-byte 0xff window at every 64-byte offset;
- 10 seeded xors of 1-8 bytes;
- 3 targeted fills of the structure record.

Each trial is one plain `ensureDb()` in a fresh process on a fresh copy.

| Variant | Trials / pages | Opened | SQLITE_CORRUPT → WAL arm | NOTADB → WAL arm | SQLITE_ERROR → rethrow | VTAB → FTS arm |
|---|---|---|---|---|---|---|
| base (fast path) | 3709 / 50 | 3706 | 2 | 1 | 0 | 0 |
| vac (fast path, every page) | 10076 / 136 | 9763 | 311 | 1 | 1 | 0 |
| behind (migration pass) | 3709 / 50 | 3706 | 2 | 1 | 0 | 0 |
| behindvac | 10076 / 136 | 9757 | 317 | 1 | 1 | 0 |
| nullterms (backfill runs) | 3783 / 51 | 3780 | 2 | 1 | 0 | 0 |

Why nothing can route there on this SQLite:
1. **FTS5 does not read the structure record when a table connects; it reads it at the first
   query.** With `events_fts`'s structure record damaged (read-only probe):
   - `PRAGMA table_info(events_fts)` → OK
   - `pragma_table_info('events_fts')` → OK
   - `SELECT count(*) FROM events_fts` → `SQLITE_CORRUPT_VTAB: fts5: corrupt structure record`

   Damage in `%_config` surfaced as plain SQLITE_CORRUPT or SQLITE_ERROR, never VTAB.
2. **The one open-path statement that reads an FTS index swallows its error.** A trace of the
   `nullterms` open:
   - `UPDATE events SET search_terms = ? … -> SQLITE_CORRUPT_VTAB`
   - `ensureDb returned a handle`

   The catch is at schema.mjs:1725-1729 (20d94507). The migration pass touched the FTS tables
   only through sqlite_master selects, `PRAGMA table_info`, `CREATE TRIGGER IF NOT EXISTS` and
   savepoints.

### Q2: the arms with an injected entry (what the arm does IF entered)
`SQLITE_CORRUPT_VTAB` is thrown at the first `journal_mode = WAL` pragma, the site of
`FAULT_SITES.pragma` in tests/wal-recovery.test.mjs. Each arm ran 20 times on fresh copies.

| Fixture | Arm | Call 1 | Main after call 1 | Call 2 (new process, 20d94507 code) | After call 2 |
|---|---|---|---|---|---|
| S0 no damage | A / B | handle 20/20 | same rows and integrity both arms | handle | same |
| S1 page 1, bytes 100..300 = 0xff | A | threw SQLITE_CORRUPT, ftsRebuildAttempted | page 1 = damaged image, WAL 0 B, 20/20 | threw | every count throws |
| | B | same throw | page 1 pristine, damaged frame still newest in the WAL, 20/20 | handle (the WAL-delete branch) | 300/200/50/20 rows, the 92 WAL-only rows lost, ok/ok |
| S2 observations_fts structure record | A / B | handle 20/20, rebuild clean | A: page 65 = rebuilt image | handle | same, both arms |
| S3 events leaf p134 | A / B | handle 20/20, rebuild reported malformed | both: page 134 damaged once the caller's own close runs | handle | same, both arms |

Verdict:
- **Real damage:** the two arms are identical, because the arm is never reached.
- **Injected entry:**
  - A is worse in S1. That needs a VTAB error from somewhere else together with a damaged
    non-FTS page in the WAL: two independent faults.
  - In S0, S2 and S3 the arms end the same (60/60 per arm). The caller's own `db.close()` on
    the returned handle checkpoints anyway.

Closed by the rule: not reproducible with real damage.

NOT CHECKED (from the run):
- other SQLite / better-sqlite3 versions (reason 1 is specific to 3.53.4);
- more than one damaged page, or a frame that is not the newest;
- torn frames, or WAL-header damage;
- older schema layouts;
- the busy-deadline cap, and another connection open;
- why `integrity_check` threw instead of returning rows in S1/S3.

Side observation: in `vac`/`behindvac` one window over an FTS table's `sqlite_schema` row made
the FTS5 connect fail with `SQLITE_ERROR: unrecognized option`. `ensureDbWithWalRecovery`
rethrows it with no recovery.

### Scripts (as run, from the subagent report)
**walfmt.mjs**
```js
// WAL / b-tree helpers shared by the D#524 probe scripts.
// WAL checksum: SQLite fileformat2 section 4.1 (same arithmetic as tests/wal-recovery.test.mjs walChecksum).
import { createHash } from 'node:crypto';

export function walChecksum(buf, s0, s1, bigEndian) {
  for (let i = 0; i + 7 < buf.length; i += 8) {
    const a = bigEndian ? buf.readUInt32BE(i) : buf.readUInt32LE(i);
    const b = bigEndian ? buf.readUInt32BE(i + 4) : buf.readUInt32LE(i + 4);
    s0 = (s0 + a + s1) >>> 0;
    s1 = (s1 + b + s0) >>> 0;
  }
  return [s0, s1];
}

export function parseWal(wal) {
  const bigEndian = wal.readUInt32BE(0) === 0x377f0683;
  const pageSize = wal.readUInt32BE(8);
  const frames = [];
  for (let off = 32, i = 0; off + 24 + pageSize <= wal.length; off += 24 + pageSize, i++) {
    frames.push({ i, off, pgno: wal.readUInt32BE(off), commit: wal.readUInt32BE(off + 4) });
  }
  return { bigEndian, pageSize, frames };
}

/** Re-sign every frame; the chain is cumulative from the WAL header. Returns a new buffer. */
export function resign(walIn) {
  const wal = Buffer.from(walIn);
  const { bigEndian, pageSize, frames } = parseWal(wal);
  let [s0, s1] = walChecksum(wal.subarray(0, 24), 0, 0, bigEndian);
  for (const f of frames) {
    [s0, s1] = walChecksum(wal.subarray(f.off, f.off + 8), s0, s1, bigEndian);
    [s0, s1] = walChecksum(wal.subarray(f.off + 24, f.off + 24 + pageSize), s0, s1, bigEndian);
    wal.writeUInt32BE(s0, f.off + 16);
    wal.writeUInt32BE(s1, f.off + 20);
  }
  return wal;
}

/** Whether the stored frame checksums verify (count of leading valid frames). */
export function validPrefix(wal) {
  const { bigEndian, pageSize, frames } = parseWal(wal);
  let [s0, s1] = walChecksum(wal.subarray(0, 24), 0, 0, bigEndian);
  let n = 0;
  for (const f of frames) {
    [s0, s1] = walChecksum(wal.subarray(f.off, f.off + 8), s0, s1, bigEndian);
    [s0, s1] = walChecksum(wal.subarray(f.off + 24, f.off + 24 + pageSize), s0, s1, bigEndian);
    if (wal.readUInt32BE(f.off + 16) !== s0 || wal.readUInt32BE(f.off + 20) !== s1) break;
    n++;
  }
  return n;
}

export function newestFrame(frames, pgno) {
  let best = null;
  for (const f of frames) if (f.pgno === pgno) best = f;
  return best;
}

export function readVarint(buf, off) {
  let v = 0n;
  for (let i = 0; i < 8; i++) {
    const b = buf[off + i];
    v = (v << 7n) | BigInt(b & 0x7f);
    if (!(b & 0x80)) return { value: v, len: i + 1 };
  }
  v = (v << 8n) | BigInt(buf[off + 8]);
  return { value: v, len: 9 };
}

/** Cells of a table-leaf page image: [{rowid, cellOff, payloadOff, payloadLen}]. */
export function tableLeafCells(page, pgno) {
  const h = pgno === 1 ? 100 : 0;
  if (page[h] !== 0x0d) return null;
  const n = page.readUInt16BE(h + 3);
  const cells = [];
  for (let i = 0; i < n; i++) {
    const cellOff = page.readUInt16BE(h + 8 + 2 * i);
    const pl = readVarint(page, cellOff);
    const rid = readVarint(page, cellOff + pl.len);
    cells.push({
      rowid: Number(rid.value),
      cellOff,
      payloadOff: cellOff + pl.len + rid.len,
      payloadLen: Number(pl.value),
    });
  }
  return cells;
}

/** For a (id INTEGER PRIMARY KEY, block BLOB) record: offset/length of the blob inside the page. */
export function blobOfDataCell(page, cell) {
  const hdr = readVarint(page, cell.payloadOff);
  let p = cell.payloadOff + hdr.len;
  const t0 = readVarint(page, p); // id column: rowid alias, serial type 0
  p += t0.len;
  const t1 = readVarint(page, p);
  const serial = Number(t1.value);
  if (serial < 12 || serial % 2 !== 0) throw new Error(`block serial type ${serial} is not a blob`);
  return { blobOff: cell.payloadOff + Number(hdr.value), blobLen: (serial - 12) / 2 };
}

export const sha = (buf) => createHash('sha256').update(buf).digest('hex').slice(0, 16);
```

```js
  }
```

```js
import { join } from 'node:path';
import { spawn } from 'node:child_process';
import { parseWal, resign, newestFrame, tableLeafCells, blobOfDataCell } from './walfmt.mjs';

const [tree, work, base, label, concS, winS = '64', xorS = '0'] = process.argv.slice(2);
const conc = Number(concS);
const win = Number(winS);
const xorSeeds = Number(xorS);

const probe = join(import.meta.dirname, 'probe-open.mjs');
const outFile = join(work, `sweep-${label}.jsonl`);
rmSync(outFile, { force: true });

const rng = (seed) => () => {
  seed = (seed + 0x6d2b79f5) | 0;
  let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
  t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
};

const trials = [];
for (const pgno of map.walPages) {
  const f = newestFrame(frames, pgno);
  const table = map.pageTable[pgno]?.name ?? '(beyond db / freelist)';
  for (let off = 0; off < pageSize; off += win) trials.push({ pgno, table, kind: 'ff', off, len: win, f });
  for (let s = 1; s <= xorSeeds; s++) {
    const r = rng(pgno * 1000 + s);
    const n = 1 + Math.floor(r() * 8);
    const off = Math.floor(r() * (pageSize - n));
    const xs = Array.from({ length: n }, () => 1 + Math.floor(r() * 255));
    trials.push({ pgno, table, kind: 'xor', off, len: n, xs, f });
  }
  const page = clean.subarray(f.off + 24, f.off + 24 + pageSize);
  const cell = /_fts_data$/.test(table) ? tableLeafCells(page, pgno)?.find((c) => c.rowid === 10) : null;
  if (cell) {
    const { blobOff, blobLen } = blobOfDataCell(page, cell);
    trials.push({ pgno, table, kind: 'struct-ff16', off: blobOff + 4, len: Math.min(16, blobLen - 4), f });
    trials.push({ pgno, table, kind: 'struct-ffall', off: blobOff, len: blobLen, f });
    trials.push({ pgno, table, kind: 'struct-zero-cookie+', off: blobOff, len: Math.min(8, blobLen), f, fill: 0 });
  }
}

function makeWal(t) {
  const wal = Buffer.from(clean);
  const s = t.f.off + 24 + t.off;
  if (t.kind === 'xor') t.xs.forEach((x, i) => (wal[s + i] ^= x));
  else wal.fill(t.fill ?? 0xff, s, s + t.len);
  return resign(wal);
}

  mkdirSync(dir, { recursive: true });
  writeFileSync(join(dir, 'claude-mem-lite.db'), pristine);
  writeFileSync(join(dir, 'claude-mem-lite.db-wal'), makeWal(t));

  const env = { ...process.env, CLAUDE_MEM_DIR: dir, MEM_NO_AUTO_ADOPT: '1' };
  delete env.ANTHROPIC_API_KEY;
  delete env.OPENROUTER_API_KEY;
  return new Promise((res) => {

    let err = '';
    c.stdout.on('data', (d) => (out += d));
    c.stderr.on('data', (d) => (err += d));
    c.on('close', (code) => {
      let r;
      try {
        r = JSON.parse(out.trim().split('\n').pop());
      } catch {
        r = { ok: false, code: `CHILD_EXIT_${code}`, message: err.slice(-300) };
```

```js
import { spawn } from 'node:child_process';

const pristineImg = sha(pristine.subarray((P - 1) * pageSize, P * pageSize));

rmSync(outFile, { force: true });
const F = ['claude-mem-lite.db', 'claude-mem-lite.db-wal', 'claude-mem-lite.db-shm'];

function child(script, args, dir) {
  const env = { ...process.env, CLAUDE_MEM_DIR: dir, MEM_NO_AUTO_ADOPT: '1', PROBE_PGNO: String(P ?? 0) };
  delete env.ANTHROPIC_API_KEY;
  delete env.OPENROUTER_API_KEY;
  return new Promise((res) => {
    const c = spawn(process.execPath, [join(here, script), ...args], { env, stdio: ['ignore', 'pipe', 'pipe'] });
    let out = '';
    let err = '';
    c.stdout.on('data', (d) => (out += d));
    c.stderr.on('data', (d) => (err += d));
    c.on('close', (code) => {
      try {
        res(JSON.parse(out.trim().split('\n').pop()));
      } catch {
        res({ childExit: code, stderr: err.slice(-300) });
      }
    });
  });
}

function pageState(dir) {
  const mainBuf = readFileSync(join(dir, F[0]));
  const m = sha(mainBuf.subarray((P - 1) * pageSize, P * pageSize));
  const mainImg = m === dmg.damagedImageSha ? 'DAMAGED' : m === cleanImg ? 'clean-wal-image' : m === pristineImg ? 'pristine' : `other`;
  let walImg = 'no-wal';
  const wp = join(dir, F[1]);
  if (existsSync(wp)) {
    const wal = readFileSync(wp);
    if (wal.length < 32) walImg = `wal-${wal.length}B`;
    else {
      const p = parseWal(wal);
      const valid = p.frames.slice(0, validPrefix(wal));
      const f = newestFrame(valid, P);
      if (!f) walImg = `no-frame-for-P (${valid.length} valid frames)`;
      else {
        const s = sha(wal.subarray(f.off + 24, f.off + 24 + pageSize));
        walImg = s === dmg.damagedImageSha ? 'DAMAGED (newest)' : `superseded (newest #${f.i} of ${valid.length})`;
      }
    }
  }
  return { mainBytesSha: sha(mainBuf), mainPageP: mainImg, walPageP: walImg };
}

async function measureCopy(dir, tree) {
  const mdir = `${dir}-m`;
  rmSync(mdir, { recursive: true, force: true });
  mkdirSync(mdir);
  for (const f of F.slice(0, 2)) if (existsSync(join(dir, f))) copyFileSync(join(dir, f), join(mdir, f));
  const r = await child('measure.mjs', [tree, join(mdir, F[0])], mdir);
  rmSync(mdir, { recursive: true, force: true });
  return r;
}

async function oneRun(arm, i) {
  const tree = arm === 'A' ? treeA : treeB;
  const dir = join(work, `run-${label}-${arm}-${i}`);
  rmSync(dir, { recursive: true, force: true });
  mkdirSync(dir);
  for (const f of F) copyFileSync(join(fixture, f), join(dir, f));
  const before = sha(readFileSync(join(dir, F[0])));
  const call1 = await child('run-arm.mjs', [tree, inject], dir);
  const after1 = pageState(dir);
  const meas1 = await measureCopy(dir, tree);
  const call2 = await child('run-arm.mjs', [tree, 'none'], dir);
  const after2 = pageState(dir);
  const meas2 = await measureCopy(dir, tree);
  rmSync(dir, { recursive: true, force: true });
  if (call1.afterCall) call1.afterCall.mainPageP = imgName(call1.afterCall.mainPageP);
  const rec = { arm, i, before, call1, after1, mainChanged1: after1.mainBytesSha !== before, meas1, call2, after2, mainChanged2: after2.mainBytesSha !== before, meas2 };
  appendFileSync(outFile, JSON.stringify(rec) + '\n');
}

const jobs = [];
for (let i = 1; i <= N; i++) for (const arm of ['A', 'B']) jobs.push([arm, i]);
let next = 0;
await Promise.all(
  Array.from({ length: Number(concS) }, async () => {
    while (next < jobs.length) await oneRun(...jobs[next++]);
  }),
);
console.error(`${label}: ${jobs.length} runs -> ${outFile}`);
```
