# v6.31.0 measurements: doctor's integrity check and the README's `.recover` steps (D#550)

The release tree's numbers, after the round-1 reviews narrowed the check, are in
[20261022-v6.31.0-d550-r2-measurements.md](20261022-v6.31.0-d550-r2-measurements.md); this file
describes the tree round 1 reviewed (1b23dcc2).

Taken 2026-10-22 on branch `feat/d550-doctor-integrity` (from `main` @ d3de9748), Linux, Node 26.8.1,
better-sqlite3 13.0.3 (SQLite 3.53.4), system sqlite3 3.46.1. Every child ran with HOME, TMPDIR and
CLAUDE_PROJECT_DIR inside `~/.cache/tmp/d550`, MEM_NO_AUTO_ADOPT=1, CLAUDE_MEM_SKIP_UPDATE=1,
CLAUDE_MEM_SKIP_MAINTAIN=1, key and proxy variables unset; the recovery ruler's children also had
PATH=/usr/bin:/bin (no `claude`), no CLAUDECODE / CLAUDE_CODE_* variables and
CLAUDE_MEM_SKIP_SAVE_ENRICH=1.

## Populations

`plants.mjs` (below) builds the stores and plants one damage each:

- `869`: a store of 200 checkpointed observations, then a log of 40 inserts, a VACUUM and one more
  insert; one damaged log frame per plant (79 pages x 11 variants), the frame chain re-signed.
- `main:21:800`, `two:22:300`, `log:23:800`: a richer store (1,195 observations and the other
  tables, plus `zz_values`, a fixture of blobs, extreme integers and text holding a NUL, and
  `zz_noindex`); damage in the main file, two damaged leaves, and damaged log frames.

## The README's recovery, run verbatim (`recover.mjs`)

For each plant that fails `lib/db-integrity.mjs`'s check: the plant at
`~/.claude-mem-lite/claude-mem-lite.db` in a sandbox HOME; README.md's first bash block under
"### Damaged database" run as one bash script; its second block only when the first printed exactly
`ok`; the recovered rows read at once; then `cli.mjs doctor`, a `save` and a `search` through the
product, and `doctor` again.

| Population | Plants | Fail the check | Stopped | Printed `ok`, placed | doctor green after | save + search | Kept copy = as found |
|---|---|---|---|---|---|---|---|
| 869 | 869 | 286 | 75 | 211 | 211 | 211 | 286 |
| main:21:800 | 800 | 530 | 11 | 519 | 519 | 519 | 530 |
| two:22:300 | 300 | 273 | 2 | 271 | 271 | 271 | 273 |
| log:23:800 | 800 | 554 | 14 | 540 | 540 | 540 | 554 |
| **all** | 2,769 | **1,643** | **102** | **1,541** | **1,541** | **1,541** | **1,643** |

Why it stopped (102): `.recover` could not read the file on 49 ("file is not a database" 2,
"database disk image is malformed" 25, "malformed database schema" 22); a search table could not be
rebuilt on 53 ("vtable constructor failed", "invalid fts5 file format", "no such table: *_fts", and
three garbled FTS definitions).

On the 1,541 placed, against what SQL reads from the damaged store (a rowid lookup and both scans,
plain and writable_schema handles), product tables only (not `zz_values`, `zz_noindex`,
`sqlite_sequence`): 157 stores lack or differ on 3,285 rows SQLite could still read intact. Rows
whose values differ from the store before the damage: 223 stores. Rows with a rowid the store never
had: 3 stores, one row each. `lost_and_found` rows: 558 stores. `zz_values`: every text value holding
a NUL comes back cut at the NUL (checked directly: `ab\0cd` → `ab`).

Why not `.dump` (`explore.mjs`, same 1,370 failing plants of 869 / main / log): `.dump` ends with a
rollback after an error, so its result often loads no observation at all and still passes its
integrity check (752 plants); `.recover` failed on 49 and otherwise recovered far more rows.

Without `.dbconfig defensive off` (one run, the first draft): sqlite3 refused the
`sqlite_master` writes that recreate the FTS5 tables ("table sqlite_master may not be modified"),
the shadow tables loaded as plain tables, and `initSchema` failed on the result
("fts5: error creating shadow table observations_fts_data: table 'observations_fts_data' already
exists").

## doctor on the 869 plants (`doctor.mjs`)

`install.mjs doctor` of this tree on each plant; "fails" = integrity_check of main + log, or of the
main file alone, fails on copies after doctor. 869 plants, 286 fail: ✗ printed on 286 (240
"Database integrity", 46 "Database" when the file will not open), ✗ on 0 passing plants, false
greens 0, bytes written to a failing store 0. Writes to the 583 passing stores come from the
existing read-write FTS check, as on `main`.

## Cost (`time.sh`)

A store of 150,000 observations (389,509,120 bytes, `gen.mjs`), doctor of `main` and of this branch
alternating, 5 runs each, load 2.5-2.9: `main` 1,280-1,298 ms (median 1,288), branch 2,005-2,124 ms
(median 2,015). On the same store `checkIntegrity` takes 704-714 ms, of which `PRAGMA
integrity_check` 635-645 ms and the observations CHECK scan 70-72 ms.

### d550/recover.mjs

```javascript
// node recover.mjs <population> <k> <K> <outFile>
//   population: 869 | main:<seed>:<count> | two:<seed>:<count> | log:<seed>:<count> (tasks/d546/ruler/plants.mjs)
// For each plant that fails lib/db-integrity.mjs's check: a sandbox HOME with the plant at
// ~/.claude-mem-lite/claude-mem-lite.db (and -wal); README.md's first bash block under
// "### Damaged database", run verbatim in one bash with that HOME, and its second block only when the
// first printed `ok` (as the README says); then this tree's `cli.mjs doctor`, twice.
// Records per plant: each line's exit code; the copy in ~/cml-recover against the store as found;
// recovered rows against the truth (intact / changed / extra) and against what SQLite reads from
// the store as found (readable intact rows the recovery lacks); lost_and_found rows; doctor's
// integrity and FTS lines after.
import { spawnSync } from 'node:child_process';
import { appendFileSync, copyFileSync, existsSync, mkdirSync, readFileSync, rmSync } from 'node:fs';
import { join, resolve } from 'node:path';
import { DB, WORK, build869, copyPair, fresh, plant869, plants869, readable, record, richPlants, sha } from '../d546/ruler/plants.mjs';
const TREE = resolve(new URL('../../', import.meta.url).pathname);
const { checkIntegrity } = await import(`${TREE}/lib/db-integrity.mjs`);

const readme = readFileSync(join(TREE, 'README.md'), 'utf8');
const section = readme.slice(readme.indexOf('### Damaged database'), readme.indexOf('## Uninstall'));
const blocks = [...section.matchAll(/```bash\n([\s\S]*?)```/g)].map((m) => m[1]);
if (blocks.length !== 3) throw new Error(`expected 3 bash blocks, found ${blocks.length}`);
const [recoverBlock, placeBlock] = blocks;

const [pop, kS, KS, out] = process.argv.slice(2);
const k = Number(kS);
const K = Number(KS);
const slot = `r${k}`;
let plants;
let truth;
if (pop === '869') {
  const base = build869();
  truth = record(copyPair(join(base, 'unplanted', DB), join(WORK, 'scratch', slot, 'truth')));
  plants = plants869().map((x) => ({ id: x.id, make: (dir) => plant869(dir, x) }));
} else {
  const [variant, seedS, countS] = pop.split(':');
  const r = richPlants(variant, Number(countS), Number(seedS), slot);
  plants = r.plants;
  truth = record(copyPair(r.tpl, join(WORK, 'scratch', slot, 'truth')));
}
const truthIds = Object.fromEntries(Object.entries(truth).map(([t, m]) => [t, [...m.keys()]]));

const env = (home) => {
  const e = { ...process.env, HOME: home, TMPDIR: join(home, 'tmp'), CLAUDE_PROJECT_DIR: join(home, 'proj'), MEM_NO_AUTO_ADOPT: '1', CLAUDE_MEM_SKIP_UPDATE: '1', CLAUDE_MEM_SKIP_MAINTAIN: '1', MEM_QUIET_HOOKS: '1' };
  delete e.CLAUDE_MEM_DIR;
  // No LLM: no keys, no `claude` on PATH (node runs by its absolute path), no host-session variables,
  // and save's background enrichment off.
  for (const key of Object.keys(e))
    if (/API_KEY|OPENROUTER|ANTHROPIC|OPENAI|_PROXY$|^CLAUDECODE$|^CLAUDE_CODE_/i.test(key)) delete e[key];
  e.PATH = '/usr/bin:/bin';
  e.CLAUDE_MEM_SKIP_SAVE_ENRICH = '1';
  return e;
};
const bash = (script, home) => spawnSync('bash', ['-c', script], { env: env(home), cwd: home, encoding: 'utf8', timeout: 300000 });

let prevHome = null;
for (let i = 0; i < plants.length; i++) {
  if (i % K !== k) continue;
  const pl = plants[i];
  // A home per plant: a child of the previous plant still writing cannot break this one.
  const home = join(WORK, 'rec', slot, String(i));
  fresh(home);
  try {
    if (prevHome) rmSync(prevHome, { recursive: true, force: true });
  } catch {
    /* removed at the end */
  }
  prevHome = home;
  for (const d of ['tmp', 'proj']) mkdirSync(join(home, d), { recursive: true });
  const dataDir = join(home, '.claude-mem-lite');
  const p = pl.make(dataDir);
  const ic = checkIntegrity(copyPair(p, join(WORK, 'scratch', slot, 'ic')));
  if (ic.ok || ic.notChecked) {
    appendFileSync(out, JSON.stringify({ id: pl.id, integrity: ic.ok ? 'ok' : `notChecked: ${ic.notChecked}` }) + '\n');
    continue;
  }
  const asFound = { main: sha(p), wal: sha(`${p}-wal`) };
  const rA = readable(copyPair(p, join(WORK, 'scratch', slot, 'ra')), truthIds);
  const res = { id: pl.id, integrity: 'fail', problems: [] };
  const t0 = Date.now();
  const one = bash(recoverBlock, home);
  res.rc1 = one.status;
  res.stderr1 = one.stderr.slice(0, 400);
  const w = join(home, 'cml-recover');
  res.step = !existsSync(join(w, DB)) ? 'copy' : !existsSync(join(w, 'recovered.sql')) || one.stderr.includes('.recover') ? 'recover' : null;
  const copy = join(w, DB);
  res.copyAsFound = sha(copy) === asFound.main && (asFound.wal === null || sha(`${copy}-wal`) === asFound.wal);
  const last = one.stdout.trim().split('\n').at(-1) ?? '';
  res.recoveredCheck = last.slice(0, 160);
  if (one.status === 0 && one.stdout.trim() === 'ok') {
    const two = bash(placeBlock, home);
    res.rc2 = two.status;
    res.stderr2 = two.stderr.slice(0, 400);
    res.ms = Date.now() - t0;
    // The recovered rows as placed, before doctor and the probe below write anything.
    let rec;
    try {
      rec = record(p);
    } catch (e) {
      res.problems.push(`recovered store unreadable: ${e.message}`);
    }
    const doc = spawnSync(process.execPath, [join(TREE, 'cli.mjs'), 'doctor'], { env: env(home), cwd: join(home, 'proj'), encoding: 'utf8', timeout: 120000 });
    res.doctor = doc.stdout.split('\n').filter((l) => /Database|FTS5|DB schema/.test(l) && !/Disk footprint/.test(l)).map((l) => l.trim());
    // The product itself, after the recovery: a save, then a search that finds it.
    const cli = (args) => spawnSync(process.execPath, [join(TREE, 'cli.mjs'), ...args], { env: env(home), cwd: join(home, 'proj'), encoding: 'utf8', timeout: 120000 });
    const saved = cli(['save', '--type', 'discovery', 'zzrecoveryprobe after the README recovery']);
    const found = cli(['search', 'zzrecoveryprobe']);
    res.save = { rc: saved.status, err: (saved.stderr || '').slice(0, 200), found: found.status === 0 && /zzrecoveryprobe/.test(found.stdout) };
    // doctor again, after the product opened the store (a session start does the same).
    const doc2 = spawnSync(process.execPath, [join(TREE, 'cli.mjs'), 'doctor'], { env: env(home), cwd: join(home, 'proj'), encoding: 'utf8', timeout: 120000 });
    res.doctor2 = doc2.stdout.split('\n').filter((l) => /Database|FTS5|DB schema/.test(l) && !/Disk footprint/.test(l)).map((l) => l.trim());
    if (rec) {
      res.lostAndFound = rec.lost_and_found?.size ?? 0;
      const c = {};
      for (const [t, m] of Object.entries(truth)) {
        const a = rec[t] ?? new Map();
        const intact = [...m].filter(([id, row]) => a.get(id) === row).length;
        const changed = [...a].filter(([id, row]) => m.has(id) && m.get(id) !== row).length;
        const extra = [...a.keys()].filter((id) => !m.has(id)).length;
        const readIntact = [...(rA[t] ?? new Map())].filter(([id, row]) => m.get(id) === row);
        const missedReadable = readIntact.filter(([id, row]) => a.get(id) !== row).length;
        c[t] = { truth: m.size, intact, changed, extra, readIntact: readIntact.length, missedReadable };
      }
      res.tables = c;
    }
  } else res.ms = Date.now() - t0;
  appendFileSync(out, JSON.stringify(res) + '\n');
}
const W = join(WORK, 'rec', slot);
for (let t = 0; t < 5; t++) {
  try {
    rmSync(W, { recursive: true, force: true });
    break;
  } catch {
    await new Promise((r) => setTimeout(r, 1000));
  }
}
```

### d550/summary.mjs

```javascript
// node summary.mjs <tag...>: the README recovery's outcome per population.
import { readFileSync, readdirSync } from 'node:fs';
import { join } from 'node:path';
const W = process.env.D546_WORK || `${process.env.HOME}/.cache/tmp/d550`;
const SKIP = new Set(['sqlite_sequence', 'zz_values']);
for (const tag of process.argv.slice(2)) {
  const rows = readdirSync(join(W, 'out', tag))
    .filter((f) => f.endsWith('.jsonl'))
    .flatMap((f) => readFileSync(join(W, 'out', tag, f), 'utf8').trim().split('\n').filter(Boolean).map((l) => JSON.parse(l)));
  const failing = rows.filter((r) => r.integrity === 'fail');
  const stopped = failing.filter((r) => r.rc2 === undefined);
  const placed = failing.filter((r) => r.rc2 === 0);
  const why = {};
  for (const r of stopped) {
    const k = (r.stderr1.split('\n').find((l) => /rror/.test(l)) ?? (r.recoveredCheck || `rc ${r.rc1}`)).replace(/\(\w+\)|near line \d+|main\.\w+/g, '').replace(/"[^"]*"/g, '"…"').slice(0, 70);
    why[k] = (why[k] ?? 0) + 1;
  }
  let missedPlants = 0, missedRows = 0, readIntact = 0, intact = 0, changed = 0, extra = 0, valuesChanged = 0;
  const missedBy = {};
  for (const r of placed) {
    let m = 0;
    for (const [t, v] of Object.entries(r.tables ?? {})) {
      if (t === 'zz_values') valuesChanged += v.changed;
      if (SKIP.has(t)) continue;
      m += v.missedReadable; readIntact += v.readIntact; intact += v.intact; changed += v.changed; extra += v.extra;
      if (v.missedReadable) missedBy[t] = (missedBy[t] ?? 0) + v.missedReadable;
    }
    if (m) { missedPlants++; missedRows += m; }
  }
  const green = placed.filter((r) => r.doctor2?.some((l) => /✓ Database integrity: ok/.test(l)) && !r.doctor2.some((l) => /^✗/.test(l))).length;
  const ftsOk2 = placed.filter((r) => r.doctor2?.some((l) => /FTS5 integrity: all indexes healthy/.test(l))).length;
  const saveOk = placed.filter((r) => r.save?.rc === 0 && r.save.found).length;
  const copyBad = failing.filter((r) => !r.copyAsFound).length;
  console.log(`\n== ${tag}: ${rows.length} plants, ${failing.length} fail the check`);
  console.log(JSON.stringify({ stopped: stopped.length, placed: placed.length, copyNotAsFound: copyBad, doctorGreenAfter: green, ftsHealthyAfter: ftsOk2, saveAndSearchOk: saveOk, missedReadablePlants: missedPlants, missedReadableRows: missedRows, readIntactRows: readIntact, intactRows: intact, changedRows: changed, extraRows: extra, zzValuesChanged: valuesChanged }));
  console.log(' stopped because:', JSON.stringify(why));
  console.log(' missed readable rows by table:', JSON.stringify(missedBy));
  const ms = placed.map((r) => r.ms).sort((a, b) => a - b);
  console.log(` procedure ms median ${ms[Math.floor(ms.length / 2)]} max ${ms.at(-1)}`);
}
```

```javascript
// two recoveries on a copy with the system sqlite3 — `.recover` and `.dump` — each loaded with

const FTS = ['observations_fts', 'session_summaries_fts', 'user_prompts_fts', 'events_fts'];
const REBUILD = FTS.map((t) => `INSERT INTO ${t}(${t}) VALUES('rebuild');`).join(' ');

const [pop, kS, KS, out] = process.argv.slice(2);
const k = Number(kS);
const K = Number(KS);
const slot = `x${k}`;
let plants;
let truth;
if (pop === '869') {
  const base = build869();

  plants = plants869().map((x) => ({ id: x.id, make: (dir) => plant869(dir, x) }));
} else {
  const [variant, seedS, countS] = pop.split(':');
  const r = richPlants(variant, Number(countS), Number(seedS), slot);
  plants = r.plants;
  truth = record(copyPair(r.tpl, join(WORK, 'scratch', slot, 'truth')));

const truthIds = Object.fromEntries(Object.entries(truth).map(([t, m]) => [t, [...m.keys()]]));
const sh = (cmd, cwd) => spawnSync('bash', ['-c', cmd], { cwd, encoding: 'utf8', timeout: 300000 });

for (let i = 0; i < plants.length; i++) {
  if (i % K !== k) continue;
  const pl = plants[i];
  const dir = join(WORK, 'exp', slot);
  const p = pl.make(dir);
  const ic = checkIntegrity(copyPair(p, join(WORK, 'scratch', slot, 'ic')));
  if (ic.ok || ic.notChecked) continue;
  const rA = readable(copyPair(p, join(WORK, 'scratch', slot, 'ra')), truthIds);
  const res = { id: pl.id };
  for (const how of ['recover', 'dump']) {

    copyPair(p, w);
    const r1 = sh(`sqlite3 -readonly ${DB} .${how} > out.sql`, w);

    const r3 = sh(`sqlite3 new.db "${REBUILD}"`, w);
    const r4 = sh(`sqlite3 new.db 'PRAGMA integrity_check'`, w);

      const rec = record(join(w, 'new.db'));
      a.tables = {};

        const got = rec[t] ?? new Map();
        const readIntact = [...(rA[t] ?? new Map())].filter(([id, row]) => m.get(id) === row);
        a.tables[t] = {
          truth: m.size,
          intact: [...m].filter(([id, row]) => got.get(id) === row).length,
          changed: [...got].filter(([id, row]) => m.has(id) && m.get(id) !== row).length,
          extra: [...got.keys()].filter((id) => !m.has(id)).length,
          readIntact: readIntact.length,
          missedReadable: readIntact.filter(([id, row]) => got.get(id) !== row).length,
        };
      }
      a.lostAndFound = rec.lost_and_found?.size ?? 0;
    } catch (e) {
      a.recordError = e.message.slice(0, 120);
    }
    res[how] = a;
  }
  appendFileSync(out, JSON.stringify(res) + '\n');
}
```

### d550/doctor.mjs

```javascript
// node doctor.mjs <k> <K> <outFile>: install.mjs doctor (this tree) on each 869 plant, in a sandbox.
// Per plant: the Database/FTS5/integrity lines doctor prints, whether it printed a ✗ on them, whether
// doctor changed the main file or the log, and integrity_check of main+log and of main alone after it
// (on copies). A false green: no ✗ on those lines while either check fails.
import { spawnSync } from 'node:child_process';
import { appendFileSync, copyFileSync, existsSync, mkdirSync } from 'node:fs';
import { join } from 'node:path';
import { DB, WORK, copyPair, fresh, plant869, plants869, sha } from '../d546/ruler/plants.mjs';
const TREE = process.env.D546_TREE || new URL('../../', import.meta.url).pathname;
const { checkIntegrity } = await import(`${TREE}/lib/db-integrity.mjs`);
const [kS, KS, out] = process.argv.slice(2);
const k = Number(kS);
const K = Number(KS);
const slot = `d${k}`;
const sbx = join(WORK, 'sbx', slot);
for (const d of ['home', 'tmp', 'proj']) mkdirSync(join(sbx, d), { recursive: true });
const env = { ...process.env, HOME: join(sbx, 'home'), TMPDIR: join(sbx, 'tmp'), CLAUDE_PROJECT_DIR: join(sbx, 'proj'), MEM_NO_AUTO_ADOPT: '1', CLAUDE_MEM_SKIP_UPDATE: '1', CLAUDE_MEM_SKIP_MAINTAIN: '1' };
for (const key of Object.keys(env)) if (/API_KEY|OPENROUTER|ANTHROPIC|OPENAI|_PROXY$/i.test(key)) delete env[key];
const plants = plants869();
for (let i = 0; i < plants.length; i++) {
  if (i % K !== k) continue;
  const pl = plants[i];
  const dir = join(WORK, 'doc', slot, 'cur');
  const p = plant869(dir, pl);
  const before = { main: sha(p), wal: sha(`${p}-wal`) };
  const r = spawnSync(process.execPath, [join(TREE, 'install.mjs'), 'doctor'], { encoding: 'utf8', env: { ...env, CLAUDE_MEM_DIR: dir }, cwd: join(sbx, 'proj'), timeout: 120000 });
  const lines = r.stdout.split('\n').filter((l) => /Database|FTS5/.test(l) && !/Disk footprint|Deeper/.test(l)).map((l) => l.trim());
  const x = lines.some((l) => l.startsWith('✗'));
  const after = { main: sha(p), wal: sha(`${p}-wal`) };
  const withLog = checkIntegrity(copyPair(p, join(WORK, 'doc', slot, 'ic')));
  const alone = (() => { const d = fresh(join(WORK, 'doc', slot, 'ica')); copyFileSync(p, d); return checkIntegrity(d); })();
  const fails = !withLog.ok || !alone.ok;
  appendFileSync(out, JSON.stringify({ id: pl.id, x, fails, falseGreen: !x && fails, changed: before.main !== after.main || before.wal !== after.wal, lines, status: r.status }) + '\n');
}
```

```javascript
function cks(buf, s0, s1, be) {
  for (let i = 0; i + 7 < buf.length; i += 8) {
    const a = be ? buf.readUInt32BE(i) : buf.readUInt32LE(i);
    const b = be ? buf.readUInt32BE(i + 4) : buf.readUInt32LE(i + 4);
    s0 = (s0 + a + s1) >>> 0;
    s1 = (s1 + b + s0) >>> 0;
  }
  return [s0, s1];
}

/**
 * The plants of one rich sweep, generated exactly as r2-defects sweep.mjs does (same PRNG order), lazily:
 * returns [{ id, make(dir) → { p, plants } }].
 */
export function richPlants(variant, count, seed, slot = 'x') {
  const R = rng(seed);
  const pick = (a) => a[Math.floor(R() * a.length)];
  const tpl = richTemplate(variant);
  const pmap = pageMap(copyPair(tpl, join(WORK, 'scratch', slot, `pm-${variant}`)));
  const offsets = [
    { off: 0, bytes: () => Array(8).fill(0x41), what: 'hdr' },
    { off: 3, bytes: () => [0, 1], what: 'ncell1' },
    { off: 3, bytes: () => [0x7f, 0xff], what: 'ncellbig' },
    { off: 8, bytes: () => [0, 0, 0xff, 0xff], what: 'right-child/ptr' },
    { off: -1, bytes: () => Array.from({ length: 16 }, () => Math.floor(R() * 256)), what: 'rand16' },
    { off: -1, bytes: () => Array(64).fill(0x41), what: 'rand64' },
  ];
  const frames = variant === 'log' ? walFrames(tpl).frames : null;
  const out = [];
  for (let i = 0; i < count; i++) {
    // Draw this plant's parameters now, in the archived order.
    const steps = [];
    const n = variant === 'two' ? 2 : 1;
    const sameTable =
      variant === 'two' ? pick(pmap.filter((x) => x.pagetype === 'leaf' && !/_fts/.test(x.name))).name : null;
    for (let k = 0; k < n; k++) {
      const o = pick(offsets);
      const bytes = o.bytes();
      if (variant === 'log') {
        const last = new Map();
        frames.forEach((f, idx) => last.set(f.pg, idx));
        const fi = pick([...last.values()]);
        const off = o.off < 0 ? 100 + Math.floor(R() * 3900) : o.off + (frames[fi].pg === 1 ? 100 : 0);
        steps.push({ wal: true, fi, off, bytes, what: o.what, pg: frames[fi].pg });
      } else {
        const cand = sameTable
          ? pmap.filter((x) => x.name === sameTable && x.pagetype === 'leaf')
          : pmap.filter((x) => x.pageno > 1);
        const pg = pick(cand);
        const off = o.off < 0 ? Math.floor(R() * 4000) : o.off;
        steps.push({ wal: false, pg: pg.pageno, off, bytes, what: o.what });
      }
    }
    const desc = steps.map((s) => ({ pg: s.pg, off: s.off, what: s.what, name: pmap.find((x) => x.pageno === s.pg)?.name }));
    out.push({
      id: `${variant}${seed}-${i}`,
      desc,
      make(dir) {
        const p = copyPair(tpl, dir);
        for (const s of steps) {
          if (s.wal) plantWal(p, s.fi, s.off, s.bytes);
          else plantMain(p, s.pg, s.off, s.bytes);
        }
        return p;
      },
    });
  }
  return { tpl, plants: out };
}

// ---------------------------------------------------------------- oracle
const SHADOW = (name, virtual) => virtual.some((v) => name.startsWith(`${v}_`));
/** Ordinary tables (not virtual, not FTS shadow, not sqlite_stat*) → Map(rowid string → row JSON). */
export function record(p) {
  const db = new Database(p, { readonly: true, fileMustExist: true });
  try {
    const all = db.prepare(`SELECT name, sql FROM sqlite_master WHERE type='table'`).all();
    const virtual = all.filter((r) => /^CREATE VIRTUAL/i.test(r.sql || '')).map((r) => r.name);
    const out = {};
    for (const { name: t } of all) {
      if (virtual.includes(t) || SHADOW(t, virtual) || /^sqlite_stat/.test(t)) continue;
      const m = new Map();
      for (const r of db.prepare(`SELECT rowid AS __rowid, * FROM "${t}" ORDER BY rowid`).safeIntegers(true).iterate()) {
        const { __rowid, ...rest } = r;
        m.set(String(__rowid), serRow(rest));
      }
      out[t] = m;
    }
    return out;
  } finally {
    db.close();
  }
}

const openRo = (p, writable) => {
  const db = new Database(p, { readonly: true, fileMustExist: true });
  if (writable) {
    db.unsafeMode(true);
    db.pragma('writable_schema = ON');
  }
  return db;
};
/**
 * Which truth rows SQLite can give back from `p` (read-only, on a copy): per table, every truth rowid a
 * `WHERE rowid = ?` lookup reads, plus every row a forward and a backward scan read before throwing, each
 * tried on a plain handle and on a writable_schema handle. Returns { t: Map(rowid → row JSON) }.
 */
export function readable(p, tables) {
  const out = {};
  for (const writable of [false, true]) {
    let db;
    try {
      db = openRo(p, writable);
    } catch {
      continue;
    }
    try {
      for (const [t, ids] of Object.entries(tables)) {
        const m = (out[t] ??= new Map());
        let one;
        try {
          one = db.prepare(`SELECT rowid AS __rowid, * FROM "${t}" WHERE rowid = ?`).safeIntegers(true);
        } catch {
          continue;
        }
        const add = (r) => {
          if (!r) return;
          const { __rowid, ...rest } = r;
          const k = String(__rowid);
          if (!m.has(k)) m.set(k, serRow(rest));
        };
        for (const id of ids) {
          try {
            add(one.get(BigInt(id)));
          } catch {
            /* unreadable */
          }
        }
        for (const dir of ['', ' DESC']) {
          try {
            for (const r of db
              .prepare(`SELECT rowid AS __rowid, * FROM "${t}" ORDER BY rowid${dir}`)
              .safeIntegers(true)
              .iterate())
              add(r);
          } catch {
            /* stopped */
          }
        }
      }
    } finally {
      db.close();
    }
  }
  return out;
}
```
